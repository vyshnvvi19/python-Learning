# Streamlit Data UX – Student Data Report

## Overview

The **Student Data Report** is a Streamlit-based data-entry and reporting application developed to demonstrate practical Data UX concepts.

The application provides a simple interface for managing student records, searching and filtering data, validating user input, and generating downloadable reports.

This project focuses on designing clear user interactions for both normal and failure scenarios.

## Objectives

- Build a user-friendly data-entry interface using Streamlit.
- Display structured student data in an interactive table.
- Implement search and filtering functionality.
- Manage application data using Streamlit session state.
- Validate user input and provide meaningful feedback.
- Handle empty and invalid data scenarios.
- Generate downloadable CSV reports from filtered data.

## Technologies Used

| Technology | Purpose |
|---|---|
| Python | Application development |
| Streamlit | Web application and user interface |
| Pandas | Data processing and CSV generation |
