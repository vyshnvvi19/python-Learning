# Streamlit – Forms & State

## Overview

This project demonstrates form handling and state management in Streamlit through a multi-step student registration workflow.

The application collects student information, validates user input, stores data using `st.session_state`, and manages the transition between different stages of the registration process.

## Objectives

- Implement Streamlit forms
- Understand and use `st.session_state`
- Implement callback functions
- Validate user input
- Manage application state and transitions
- Preserve user data across Streamlit reruns
- Build a multi-step input workflow

## Technologies Used

- Python
- Streamlit
