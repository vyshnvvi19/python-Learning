# Streamlit – Foundations

## Overview

This project introduces the fundamentals of Streamlit and demonstrates how to build an interactive data application using Python.

The application is a Student Data Viewer that allows users to search, filter, and explore student information through Streamlit widgets and visualizations.

## Objectives

- Understand how a Streamlit application runs
- Learn basic Streamlit text and output functions
- Use interactive widgets
- Display tabular data
- Create charts
- Use layouts with columns
- Understand Streamlit's rerun model
- Build a multi-section data viewer

## Technologies Used

- Python
- Streamlit
