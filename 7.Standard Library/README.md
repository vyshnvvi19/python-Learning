# Task 07 — Python Standard Library

## Overview

This task focuses on using Python's built-in standard library to solve
common programming and data-processing problems efficiently. The exercises
cover date and time operations, file handling, JSON processing, regular
expressions, and log analysis.

## Concepts Covered

- `datetime` — Date and time calculations
- `pathlib` — File and directory handling
- `json` — Reading, writing, and transforming JSON data
- `csv` — Working with CSV files
- `collections` — Data counting and aggregation
- `itertools` — Basic iterator operations
- `re` — Regular expressions and pattern matching

## Practical Exercises

### 1. Date Calculator
Performs date-related calculations using the `datetime` module.

### 2. JSON Transformer
Reads structured JSON data, processes the records, and generates updated
JSON output.

### 3. Log Processing Tool
Reads application log data, identifies supported log levels, handles
invalid entries, and generates a summary of log activity.
