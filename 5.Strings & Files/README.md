# Task 4.5 — Strings & Files

## Overview

This task focuses on working with strings and files in Python. The main
project is a log parser and CSV report generator.

## Concepts Covered

- String operations
- String splitting
- `pathlib`
- Text file handling
- UTF-8 encoding
- Dictionaries and lists
- CSV file generation
- File validation
- Safe file handling

## Project

The log parser reads an application log file, identifies supported log
levels, skips invalid entries, and generates a summary.

The CSV report generator uses the parsed log data to create a CSV report
containing log counts and individual log records.
