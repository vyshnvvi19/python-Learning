# Task 02 — Control Flow

## Overview

This task focuses on using control-flow statements in Python to make
decisions, repeat operations, and control the execution of a program.

The exercises build practical understanding of conditional statements and
loops through small problem-solving programs.

## Concepts Covered

- Conditional statements: `if`, `elif`, `else`
- `for` loops
- `while` loops
- `range()`
- `break` and `continue`
- Nested loops
- Conditional expressions

## Exercises

The following programs were implemented as part of this task:

| Program | Description |
|---|---|
| `01_even_odd.py` | Checks whether a number is even or odd |
| `02_pos_neg_zero.py` | Identifies positive, negative, or zero values |
| `03_sum_of_dig.py` | Calculates the sum of digits of a number |
| `04_prime.py` | Checks whether a number is prime |
| `05_factorial.py` | Calculates the factorial of a number |
| `06_star.py` | Generates star patterns using loops |
| `07_num_pyramid.py` | Generates a number pyramid pattern |
| `08_square.py` | Generates a square pattern |
| `09_greaterthan.py` | Compares numbers and determines the greater value |
| `10_lar_small.py` | Finds the largest and smallest values |
| `11_search_num.py` | Searches for a number using control-flow logic |
| `12_student_menu.py` | Implements a menu-driven student program |
| `13_num_utility.py` | Performs multiple number-related operations |

## What I Practiced

Through these exercises, I practiced applying conditions and loops to solve
different programming problems, including number analysis, pattern
generation, searching, comparison, and menu-driven programs.

The task helped me understand how control-flow structures can be combined
to build logical and interactive Python programs.
