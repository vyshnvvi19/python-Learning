# Task 08 — Independent Challenge

## Overview

This task is an independent Python project designed to apply the concepts
learned throughout the Python Fundamentals section.

The project is a command-line Expense and Asset Tracker that allows users
to record, manage, search, summarize, and store financial records.

## Features

- Add expense and asset records
- View all records
- Search records by category or description
- Calculate total amounts
- Calculate expense and asset totals
- Generate category-wise summaries
- Export records to CSV
- Import records from CSV
- Validate dates, amounts, categories, descriptions, and record types
- Handle missing and invalid input
- Automated unit tests

## Record Structure

Each record contains:

- Date
- Category
- Description
- Amount
- Type — Expense or Asset
