# Task 05 — Python Exceptions

## Overview

This task focuses on handling errors and validating user input using Python
exception-handling mechanisms. The exercises demonstrate how to handle
expected errors, raise exceptions when validation fails, and create custom
exceptions for specific situations.

## Concepts Covered

- `try` and `except`
- `else` and `finally`
- Raising exceptions using `raise`
- Built-in exceptions such as `ValueError` and `ZeroDivisionError`
- Custom exceptions
- Input validation
- Error handling and failure handling

## Practical Exercises

The concepts are implemented through the following programs:

- Basic `try/except` error handling
- `try/except/else/finally` execution
- Age validation using `raise`
- Password validation
- Custom exception for insufficient balance
- Validation utility functions for age, email, amount, and phone number

## Learning Focus

The main focus of this task is understanding how to handle expected
validation errors separately from programming defects and how to make
programs more reliable through proper exception handling.
