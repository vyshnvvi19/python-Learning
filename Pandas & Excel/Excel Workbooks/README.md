\# Excel Workbooks



\## Overview



This module demonstrates how to work with Excel workbooks using Python and OpenPyXL.



The exercise covers reading and writing worksheets, formulas and values,

basic formatting, workbook structure, and creating a multi-sheet Excel report.



\## Topics Covered



\- Reading worksheets

\- Writing worksheets

\- Creating multiple sheets

\- Formulas and values

\- Basic cell formatting

\- Column widths

\- Number formatting

\- Workbook structure

\- Creating summary outputs
