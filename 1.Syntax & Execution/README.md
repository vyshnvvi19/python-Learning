# Task 01 — Python Syntax & Execution

## About

This task covers the fundamentals of Python programming and focuses on
understanding how Python code is written, executed, and structured.

The exercises in this folder provide hands-on practice with basic Python
concepts through small, practical programs.

## Concepts Covered

- Variables and Data Types
- Operators and Expressions
- Input and Output
- Type Conversion
- Strings and String Methods
- Comments and Indentation
- Modules and Imports
- Python Script Execution

## Programs

The folder contains practical programs such as:

- Calculator
- BMI Calculator
- Simple Interest Calculator
- Average Calculator
- Age Calculator
- Temperature Converter
- Length and Time Converter
- Volume Converter
- Grade and GPA Calculator
- Pass/Fail Checker
- Menu-Based Programs
- Number Guessing Program
- Travel Budget Calculator
- Text and Name Formatting
- Removing Extra Spaces

## What I Practiced

Through these exercises, I practiced writing Python programs from scratch,
taking user input, performing calculations, working with strings, using
modules, and producing formatted output.

This task helped establish the Python fundamentals required for the
subsequent control-flow, collections, and functions tasks.
